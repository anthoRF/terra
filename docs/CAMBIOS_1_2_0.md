# Terra 1.2.0

- Se retiran las flechas decorativas de acciones, fichas y enlaces internos. Se conservan navegación de preguntas, regreso, despliegue de detalles y giro.
- Registro con un alias. Ingreso con alias y código personal, sin código de clase. Los alumnos nuevos aparecen automáticamente en Participantes de Terra.
- Las cuentas anteriores conservan datos y se localizan por alias y código personal, incluso si comparten alias en grupos distintos.
- Los grupos y sus enlaces de invitación quedan como organización opcional del docente.
- Giro con mouse y zoom con rueda al activar la interacción mediante un clic en la Tierra o el botón Usar mouse. Terminar, Esc o un clic fuera devuelve la rueda al desplazamiento. Se conservan los botones y el modo táctil explícito.
- Fichas con Lo esencial, Un ejemplo y Pruébate. Retroalimentación inmediata sin sumar calificaciones ni intentos oficiales.
- Compilación de interfaz y función Netlify verificadas. DOCENTE_CLAVE se configura una sola vez como variable privada de producción.
