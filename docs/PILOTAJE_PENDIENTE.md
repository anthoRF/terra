# Pilotaje pendiente: protocolo de registro

Este archivo prepara la prueba con tres usuarios. No contiene resultados ni afirma que el pilotaje haya ocurrido.

## Tareas para U1, U2 y U3

1. Abrir el enlace e identificar cómo explorar una capa.
2. Cambiar entre superficie e interior; localizar agua, vida y una capa interna.
3. Completar un punto, revisar el resultado y corregir una respuesta.
4. Con una clase de prueba, crear un alias, conservar el código y recuperar el avance desde otro navegador.
5. Terminar el reto y localizar la ficha final.
6. Probar la vista ilustrada y realizar una selección con teclado o toque.

Evitar explicar la solución antes de observar cómo usa la interfaz. No recoger nombres completos, correos o datos personales. Anotar lo observado, sin atribuir comentarios que no se hayan dicho. Las pruebas técnicas automatizadas no cuentan como estos tres usuarios.
